# Removed & Hidden Features

## Sidebar Menus
- **Journeys**: Setting up frameworks, risk assessments, and compliance journeys automatically.
- **Respondent View**: Simplified view for external users to answer questionnaires.
- **Domains**: Organization domains.
- **Perimeters**: Security perimeters.
- **Teams**: Organization teams.
- **User Groups**: User groupings.
- **Role Assignments**: Assigning roles to users.

## UI Elements
- **Onboarding Pop-up**: 'Welcome to CISO Assistant!' modal that appears on first login.

## Data
- **Preset Libraries**: Default compliance frameworks and risk matrices loaded by storelibraries command.
